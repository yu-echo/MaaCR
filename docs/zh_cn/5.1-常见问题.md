# 5.1 常见问题

> 按**现象**查。每条都对应一次真实踩坑。

## 一、跑不起来 / 点了没反应

| 现象 | 怎么办 |
| --- | --- |
| 点「开始任务」没反应，日志停在「正在连接至模拟器……」 | **先看上一次的任务链是不是还卡着。** 界面上「已有任务链正在启动或运行」时会把新的启动请求**直接忽略**（日志原话：`任务启动请求已忽略：当前已有任务链正在启动或运行。`），表现就是「点了没反应」。→ **先点「停止任务」，再重新点开始。**<br>卡顿本身多半来自截图方式：`EmulatorExtras` 在**模拟器窗口最小化 / 屏幕关闭 / 设备没完全启动**时拿不到画面（日志会写 `实时画面为空：截图方式=EmulatorExtras`）。要么让 MuMu 窗口**保持可见**，要么把截图方式改成 `RawWithGzip`（不依赖窗口可见性） |
| 实时画面一直「暂无截图」/ 一黑一黑 | 同上：`EmulatorExtras` 在窗口最小化 / 息屏时返回**空帧**。让窗口保持可见，或把截图方式改成 `RawWithGzip` |
| **双击 `MFAAvalonia.exe` 报错、起不来** | 缺 **.NET 10 桌面运行时**。双击包里的 `install-deps-win.bat`，装完**重启电脑** |
| 任务列表里**一个任务都没有**，只剩「全局设置」 | 界面把上一次的任务布局**缓存**下来了。**点任务栏上面的「+」新建一个实例**，它会重新读一遍，任务就出来了（实测有效）。改过 `interface.json` 之后遇到这种情况，先试这个 |
| 别同时开多个实例 | 每个实例各建一套控制器 + adb 连接，容易互相抢 —— 实测见过「已有任务链正在启动或运行」把新请求挡掉、另一个实例空着。**同时只跑一个** |

## 二、认不出 / 卡住

| 现象 | 怎么办 |
| --- | --- |
| **所有识别都失分（匹配度 0.00）** | 大概率是**屏幕熄了** —— 模拟器闲置会自动熄屏，黑屏时模板匹配全军覆没。先手动点亮模拟器（`环境准备` 节点本来就会发一次亮屏指令，但它只在任务开头跑一次） |
| 卡在某一屏来回打转 | 看日志里反复出现的是哪两个节点名。`清障链 ⇄ 再等等` 空转 = **启动链没认出任何已知界面**（多半是弹窗遮罩或动画没结束）；`商店扫屏 ⇄ 商店滑一屏` 一直重复 = 商店确实在往下翻，等它翻完（默认最多 60 屏，可在界面上调小） |
| 报「界面未知」然后重启游戏 | 自愈走到了最后一段（`未知-重启`）。说明那一屏**既不认识、画面也不动了**。把那一屏截图发出来补个锚点就好（流程见 [2.1-识别原理](2.1-识别原理.md#四加一个新锚点或新界面状态的流程)） |

> 认不准的时候**先看 `debug/vision/` 的图** —— 那是框架自己看到的那一帧 + 识别框 + 分数，
> 比在屏幕前猜快得多。详见 [3.1-从源码跑](3.1-从源码跑.md#42-看-debugvision-的图排查认不到的第一手材料)。

## 三、对战 / 日常不出活

| 现象 | 怎么办 |
| --- | --- |
| 一直不出牌 | 检查 `出牌-圣水够` 的 `roi` 起点位置（对应界面上「对战策略」那个下拉），以及手牌模板有没有对上。**认不出就是卡面模板缺了精英 / 觉醒形态** |
| 出牌点下去没反应 | 坐标落在两行按钮中间的空隙上 —— 点了等于没点，还不报错。**每个写死坐标都要在截图上肉眼确认过** |
| 部落一个都没捐出去 | 看「部落捐一个」的 OCR 结果。它认的是 `捐赠` 这两个字（`threshold 0.3`），认到 0 个说明这屏确实没有可捐的请求；也可能是按钮**是灰的**（自己发起的请求，本来就捐不了） |
| 商店里没领到补偿礼包 | 补偿礼包只在**官方维护后**才挂在商店里。没有维护的日子扫不到是正常的；有维护但你确信没领到，看 `商店领维护礼` 的识别分数（它对的是卡片底部那条**深色**「免费！」按钮） |

## 四、安全相关

| 现象 | 怎么办 |
| --- | --- |
| 选错设备（驱动到真机了） | **纯 JSON 化之后没有设备安全检查了**（那个检查是 `tools/preflight.py`，已删）。只能靠你自己在 MFAAvalonia 里选对 **MuMu 的 `127.0.0.1:<端口>`**，没有兜底 —— 详细的坑见 [1.1-快速开始](1.1-快速开始.md#为什么非要选模拟器不选真机) |
| 它会不会花我的宝石 / 钻石 | **不会**。所有领取都要求**先识别出「免费！」再点**，不会盲点坐标。已知的例外是「请求卡牌」在冷却中盲点会弹一个花 2 宝石的确认框 —— 判据已加上（冷却时按钮会变成「请求换卡」），冷却中整步跳过 |
