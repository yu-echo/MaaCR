# 2.3 调策略与素材

> 想改行为之前先看这一页。**策略全在 JSON 里，没有配置文件** ——
> 改完直接用 [3.1 的验证方法](3.1-从源码跑.md#三怎么验证改动) 跑一遍。

## 一、改什么 → 改哪里

| 想改什么 | 改哪里 |
| --- | --- |
| **出牌优先级** | `battle.json` → `出牌-圣水够` 的 `next` 列表（**从上往下试第一张「在手」的牌**，顺序即优先级） |
| **什么时候出牌** | 同上节点的 `ColorMatch.roi` **起点 x** —— 圣水条上「够 N 费」的刻度位置。界面上的「对战策略」下拉就是改这个 x |
| 两次出牌之间的间隔 | `出-*` 各节点的 `post_delay` |
| **落点** | `落点` 节点 → 通用落点 `落点-桥头`（`DirectHit` 直接点）/ 破塔后的 `落点-破塔深位` / 哥布林飞桶专用的 `落点-飞桶`（含一塔、大本营两档） |
| **换卡组** | 把新卡面裁进 `assets/resource/image/cards/`，在 `battle.json` 加对应的 `出-xxx` 节点，再挂进 `出牌-圣水够.next` |
| 部落最多捐几次 | 界面上的「每次捐赠几张」→ `部落捐一个.max_hit` |
| **请求哪张卡** | 界面上的「**要请求的卡牌**」下拉（默认「电击法术」）→ `部落长按目标卡.recognition.param.template`。名单与模板在 `assets/resource/image/clan/request_targets/`（`card_NNN.png` + `index.json` 映射） |
| **周日狂欢请求哪张** | **写死「狂暴」**，不受上面那个下拉影响 → `部落长按目标卡-狂欢.recognition.param.template`。触发闸门是 `部落请求找卡-周日`（认弹窗顶部那条紫横幅，`ColorMatch` H[122,134] 面积≥15000）—— 横幅在就等于「史诗卡可请求」，整段列表只找狂暴，找不到就跳过 |
| 开 / 关「请求卡牌」那一步 | 界面上的「顺便请求卡牌」开关 → `部落请求卡牌.enabled` |
| 商店一屏看多久 | `商店扫屏.timeout`（默认 1.5 秒）—— 商店内容是**懒加载**的，别调太小 |
| 商店最多翻几屏 | 界面上的「商店最多翻几屏」→ `商店滑一屏.max_hit`（默认 60，现在只是**兜底预算**；正常翻到「每日精选」就收工，实测只滑 17～23 屏） |
| 找某张卡的卡面 | 看 `assets/resource/image/card_library/`（**参考图库**，见下方说明） |

### 重新采一份「选卡名单」

游戏出新卡、或你的卡升到满级之后，那份 71 张的名单会和游戏里对不上。重采一次即可：

```bash
python tools/capture_request_popup.py        # 实机逐帧采弹窗
python tools/cut_request_targets.py          # 拼长图 + 裁模板 + 正负样本验收
python tools/name_request_targets.py         # 长按取游戏内卡名
python tools/gen_request_target_option.py    # 落素材 + 生成 option cases
python tools/patch_interface_request_option.py  # 注入 interface.json
```

### ⚠️ 换卡组的坑

同一张牌有**普通形态**和**精英 / 觉醒形态**两套素材，对战时会**交替出现**。
只录一套，轮到另一套那一轮就会认不出来、白白错过出牌机会。
每套卡组最多 2 个觉醒位 ⇒ **8 张牌 + 2 个精英形态 = 10 张模板**，数量固定、不会漏。

> 日常任务那两条的判据为什么长这样（每一步都对应一次翻车），
> 单独写在 [2.2-日常任务](2.2-日常任务.md) —— 想动它们之前先读那一页。

## 二、`image/card_library/` 是什么（和模板的区别）

`card_library/` 是**全部卡面的身份库**：一张卡一个文件，文件名 = `{中文名}_{形态}.png`，
形态取 `普通` / `觉醒` / `精英`，名字就是游戏里显示的卡名（权威名册在 `index.json`）。
另有 `tower_001..004.png`（140×230）是「皇家塔部队」那 4 座塔。

现行构成（2026-10-18 实机核对后）：

| 形态 | 数量 | 状态 |
| --- | --- | --- |
| 普通 | 123 | 全部 158×194 标准缩略图 |
| 觉醒 | 44 | 已解锁 20 张 = 缩略图；未解锁 24 张 = 详情页整帧 |
| 精英 | 17 | 已解锁 6 张 = 缩略图；未解锁 11 张 = 详情页整帧 |
| 皇家塔 | 4 | 140×230 |

哪张卡有哪个形态、解锁没解锁，查 `forms.json` 的「觉醒 / 精英」两列（`已解锁` /
`未解锁` / `无此形态`）—— **判据只有一条：详情页左侧那个图标带不带挂锁**，
带挂锁 = 未解锁，那形态游戏里就没有正常卡面。

**「觉醒」是对战内机制，不是另一张卡。** 一张牌占了进化槽后，充能 2 次（正常打出 2 次），
**第 3 次**打出的是觉醒形态；觉醒打出后计数清零、重新充能。所以同一张牌的手牌卡面
会在普通 / 觉醒之间来回切 —— **战斗识别必须把两套模板挂在同一个节点上**，
只认一套就会漏掉觉醒那一次的出牌机会（手牌认不出 → 落到 `对战等待`）。
少数卡只需 1 次充能，也有要 3 次的；飞龙宝宝是 2 次。
实测：1126 帧语料覆盖 6 场对战，飞龙宝宝每场都同时出现过两种形态。

这份库**会随 `tools/sync_install.py` 一起同步进用户包**（2026-10-18 起，约 42 MB），
将来卡组从卡库调图时运行时直接读它，不用再单独拷。

**口径：缩略图统一 158×194。** 卡还没解锁时游戏里没有正常卡面（详情页左侧那个图标是
灰色带锁的占位图），这种形态先存 720×1280 的详情页整帧，等解锁再换 ——
**文件尺寸就是解锁状态的判据**：158×194 = 标准缩略图，720×1280 = 未解锁整帧。

用途是**认出「这是哪张卡」的身份基准**：卡组配置从这里按名字调卡面和形态，
以后做战斗 / 请求相关识别也先在这里找素材。

> **但缩略图本身不是模板，别直接拿去匹配。** 各场景卡面的裁切比例不一样：

| 场景 | 卡面尺寸 |
| --- | --- |
| 收藏页 / 卡牌库 | 158×194 |
| 请求捐赠弹窗 | 147×126 |
| 对战手牌 | 101×126 |

实测：直接拿 158×194 缩到目标尺寸去匹配，请求弹窗最高只有 **0.61**，对战手牌只有 **0.0x~0.5**。
但如果先搞清楚「两边的取景差多少」，一部分卡是可以**从库图直接生成模板**的：

| 卡 | 库图 → 手牌 | 生成模板同窗分 | 实际用哪套 |
| --- | --- | --- | --- |
| 亡灵 / 骷髅兵 / 浪人 / 野猪骑士 / 烈焰精灵 | 能 | 0.969 / 0.988 / 0.981 / 0.968 / 0.991 | `cards_lib/`（库图生成） |
| 飞龙宝宝 ±进化、哥布林飞桶 ±进化 | 能 | 0.983 / 0.977 / 0.984 / 0.923 | `cards/`（实战直裁，实机 0.95~0.996 更高） |
| 气球兵 | **不能**：全库 149 张逐个检索，最高 0.337 | — | `cards/` |

- 手牌那张图 = 库图**同一块美术放大 1.261 倍后裁的一块**（ORB 拟合：5 张卡内点 34~50，
  缩放一致 1.26~1.27，平移 x≈13 / y≈18）。生成器就是照这个变换裁，产物在
  `image/cards_lib/`（`python ../tools/gen_cards_from_lib.py`，改卡组后重跑一次）。
- **只裁卡面上部 89×74，不裁整卡**。整卡里混着三样两边对不上的东西：库图的外框下沿、
  「16级」等级条、手牌左下角的圣水徽章。切掉之后自匹配从 0.842~0.887 升到 0.964~0.981，
  别的牌最高 0.543；全 ROI（不是只在框内）1126 帧零漏检，还多抓到 10 帧整卡模板掉到 0.95
  以下的浪人。顺带一个好处：等级条随卡升级会变，整卡模板会失效，切掉就与等级无关。
- 能不能生成，判据不是肉眼，而是**特征拟合的内点数**：内点 ≥15 才算「同一张画」。
- ⚠️ **文件名的坑（2026-10-18 核对，已修）**：`cards/` 里飞龙宝宝、哥布林飞桶的
  「普通 / -进化」两个文件名**原来是反的**。真值取自详情页——普通页卡面是「叼蓝球」、
  页面无形态字样；觉醒页写着「觉醒」「已觉醒」、卡面是「张嘴」。两张图已互换文件名。
  之前那版文档写「这 5 张库里是另一幅画」，就是被这个反名字带出来的：按名字配对，
  怎么裁都只有 0.0x，看着像美术不同。**换了名字再看，同窗分 0.92~0.98，本来就是同一幅画。**

对应的流水线写法：`cards_lib/` 的模板阈值 **0.90**，`cards/` 的 **0.85**；
gate「对战中」继续只用 `cards/` + 0.85（它还要负责排除非战斗界面）。
