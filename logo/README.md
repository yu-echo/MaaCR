## 换 logo 只动一处

只改仓库根的 `logo.png` 就够了：

- `README.md` 头部引用的是 `./logo.png`；
- `tools/install.py` 会把它一起放进发布包（不然包里的 README 会挂一张碎图）。

## 约定

- **512×512 PNG**、正方构图，README 里按 `width="200"` 显示。
- **背景色会影响深色主题下的观感**：白底图在 GitHub 深色主题下会显示成一块白方块。
  想两全其美就得用**透明底** —— 目前这几版都是白底。要抠背景的话，
  扁平线稿请用「从边界洪泛填充近似背景色」的办法，**别用亮度阈值**：
  那样会把发色、肤色这类浅色主体也抠成半透明。
- **带水印的图不许入库。** AI 生成的图右下角会打一行半透明白水印，入库前必须抹掉；
  做法与踩过的坑记在用户级参考文档里（`reference/tools-and-services.md`）。
  判断有没有抹干净要**放大目视**，别信自制的「亮度异常」指标 —— 平滑渐变会把它骗过去。
- **源图不一定是方图，也不一定是 PNG。** 统一按这个流程过一道：
  1. 非 PNG 先用 `ffmpeg -i 源图 中转.png` 转一道。
     ⚠️ 本机没装 ImageMagick；Windows 自带的 `convert.exe` 是 **FAT→NTFS 转换工具**，
     不是图像命令，千万别当 ImageMagick 用。
  2. 量出「非白内容」的包围盒：逐行/逐列统计非白像素，**要求每行/列至少若干个像素**才算
     「这一行有内容」—— 否则边缘一个 JPEG 噪点就会把包围盒撑满整张图（实测踩过）。
  3. 以内容为中心裁正方，再
     `ffmpeg -vf "crop=边长:边长:x:y,scale=512:512:flags=lanczos"` 缩放。
     纯标准库那套（`png_tool.py`）只支持整数倍降采样，任意尺寸交给 ffmpeg 更省事。
- 想加新版本就往这里放 `05-xxx.png` 并补一行表格，**不要覆盖已有文件** ——
  这一目录的用途就是「留着还能换回去」。
