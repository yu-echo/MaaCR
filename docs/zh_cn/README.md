## 文档本身的约定

- 放在 `docs/zh_cn/` 下，**平铺 + 编号**，不建子目录（跟框架文档一致）；
  章节含义：`1.x` 入门、`2.x` 原理、`3.x` 开发。新增一页就往后排号。
- 链接一律用**相对路径** —— 发布包里也带了 `docs/`，这样在解压出来的文件夹里也点得开。
- 说「怎么做」的同时说清「为什么这么做」：这个项目的判据大半是被旧版的坑逼出来的，
  只写结论的话下一个人很容易「顺手简化」回去。
