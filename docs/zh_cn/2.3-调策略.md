# 2.3 调策略与素材

> 想改行为之前先看这一页。**策略全在 JSON 里，没有配置文件** ——
> 改完直接用 [3.1 的验证方法](3.1-从源码跑.md#三怎么验证改动) 跑一遍。

## 一、改什么 → 改哪里

| 想改什么 | 改哪里 |
| --- | --- |
| **出牌优先级** | `battle.json` → `出牌-圣水够` 的 `next` 列表（**从上往下试第一张「在手」的牌**，顺序即优先级） |
| **什么时候出牌** | 同上节点的 `ColorMatch.roi` **起点 x** —— 圣水条上「够 N 费」的刻度位置。界面上的「对战策略」下拉就是改这个 x |
| 两次出牌之间的间隔 | `出-*` 各节点的 `post_delay` |
| **落点** | `落点` 节点 → 通用落点 `落点-桥头`（`DirectHit` 直接点）/ 破塔后的 `落点-破塔深位` / 哥布林飞桶专用的 `落点-飞桶`（含一塔、大本营两档） |
| **换卡组** | 把新卡面裁进 `assets/resource/image/cards/`，在 `battle.json` 加对应的 `出-xxx` 节点，再挂进 `出牌-圣水够.next` |
| 部落最多捐几次 | 界面上的「每次捐赠几张」→ `部落捐一个.max_hit` |
| **请求哪张卡** | 界面上的「**要请求的卡牌**」下拉（默认「电击法术」）→ `部落长按目标卡.recognition.param.template`。名单与模板在 `assets/resource/image/clan/request_targets/`（`card_NNN.png` + `index.json` 映射） |
| 开 / 关「请求卡牌」那一步 | 界面上的「顺便请求卡牌」开关 → `部落请求卡牌.enabled` |
| 商店一屏看多久 | `商店扫屏.timeout`（默认 1.5 秒）—— 商店内容是**懒加载**的，别调太小 |
| 商店最多翻几屏 | 界面上的「商店最多翻几屏」→ `商店滑一屏.max_hit`（默认 60，现在只是**兜底预算**；正常翻到「每日精选」就收工，实测只滑 17～23 屏） |
| 找某张卡的卡面 | 看 `assets/resource/image/card_library/`（**参考图库**，见下方说明） |

### 重新采一份「选卡名单」

游戏出新卡、或你的卡升到满级之后，那份 71 张的名单会和游戏里对不上。重采一次即可：

```bash
python tools/capture_request_popup.py        # 实机逐帧采弹窗
python tools/cut_request_targets.py          # 拼长图 + 裁模板 + 正负样本验收
python tools/name_request_targets.py         # 长按取游戏内卡名
python tools/gen_request_target_option.py    # 落素材 + 生成 option cases
python tools/patch_interface_request_option.py  # 注入 interface.json
```

### ⚠️ 换卡组的坑

同一张牌有**普通形态**和**精英 / 觉醒形态**两套素材，对战时会**交替出现**。
只录一套，轮到另一套那一轮就会认不出来、白白错过出牌机会。
每套卡组最多 2 个觉醒位 ⇒ **8 张牌 + 2 个精英形态 = 10 张模板**，数量固定、不会漏。

> 日常任务那两条的判据为什么长这样（每一步都对应一次翻车），
> 单独写在 [2.2-日常任务](2.2-日常任务.md) —— 想动它们之前先读那一页。

## 二、`image/card_library/` 是什么（和模板的区别）

`card_library/` 是**收藏页里全部卡牌的缩略图**（`card_001..123.png`，158×194；
外加 `tower_001..004.png`，140×230，是「皇家塔部队」那 4 张），共 127 张。

用途是**当参考图库**：认出「这是哪张卡」，以及以后做战斗 / 请求相关识别时先在这里找素材。

**它不是模板，别直接拿去匹配。** 收藏页的卡面裁切比例和实际识别场景都不一样：

| 场景 | 卡面尺寸 |
| --- | --- |
| 收藏页（card_library） | 158×194 |
| 请求捐赠弹窗 | 147×126 |
| 对战手牌 | 101×126 |

实测拿收藏页的卡面去匹配请求弹窗的帧，最高只有 **0.61** —— 远低于阈值。
**要做模板，必须从目标场景的 720p 无损截图原样裁。**
