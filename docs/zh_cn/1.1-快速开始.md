# 1.1 快速开始

给「只想把它跑起来」的人。想改代码的话，直接从 [3.2-迁移对照](3.2-迁移对照.md) 开始。

## 先确认三件事

1. **Windows** —— 本项目只发 Windows 包（底层绑死了 MuMu 模拟器）。
2. **MuMu 模拟器**（实测 MuMu Player 12）里装好**国服皇室战争**
   （`com.tencent.tmgp.supercell.clashroyale`），并且你**已经手动登录过一次** ——
   微信 / QQ 授权本工具不碰，识别到登录页它会停下等你。
3. 模拟器保持 **720×1280 竖屏**，设置里打开 **USB 调试**。

> 分辨率别改。本项目全部模板图与坐标都是按 720×1280 量的，
> `interface.json` 里的 `display_short_side: 720` 也是为此 —— 换分辨率要重采全部模板并重标坐标。

## 装

1. 到 [Releases](https://github.com/yu-echo/MaaCR/releases/latest) 下载
   **`MaaCR-win-x86_64-vX.Y.Z.zip`**；
2. **解压到纯英文路径**下（中文路径容易出各种怪问题）；
3. 双击 **`MFAAvalonia.exe`**。

包里已经自带一份 Python 和全部依赖（MaaFw / opencv / numpy），
**不需要你装 Python，也不用 `pip install` 任何东西**。

如果双击报错、提示缺少 .NET：双击包里的 **`install-deps-win.bat`** 装一下
（缺 .NET 10 桌面运行时才会用到它），**装完重启电脑**再试。

## 第一次跑：先只认不打

1. 启动 MuMu（**不用自己开游戏**，工具会把它调到前台）；
2. 选设备时**选 MuMu 的 `127.0.0.1:<端口>`**（别选插着的真机，理由见下）；
3. 勾「自动对战」，把「最多打几局」设成 **1**；
4. 勾上「**演练模式（只识别不点击）**」—— 它会截图、识别、打印决策，**一次都不点**；
5. 看日志确认它认得出（识别可视化要另外开，见下面那条）。

认得准了，再把「演练模式」关掉跑一次真的。

> ⚠️ 演练模式**对所有任务生效**（对战、商店、部落都吃这个开关），不是只对战。
> 验证完记得关掉；关掉后如果它还是不动，那不是这个开关的问题。

> **关于 `debug/` 下的识别可视化图**：它由 `config/maa_option.json` 里的 `save_draw`
> 控制（`save_on_error` 存失败截图、`stdout_level` 调日志等级）。
> 但当前代码里用的是 `Toolkit.init_option`，启动时会打一行
> `Toolkit.init_option is deprecated ... only set_log_dir is applied` ——
> **这几个开关到底还生不生效，还没在实机上确认**。认不准时先看日志。

## 为什么非要选 `127.0.0.1`：只驱动模拟器，不碰真机

旧版实测过一个坑：开发机**插着的真机上装了同一个国服包**，所以按包名挑设备根本区分不开；
一旦模拟器端口全断、程序回退到「第一台在线设备」，就会去操作真机。

所以 `tools/preflight.py` 会在控制器建立**之前**检查目标设备是不是本地，
不是就**拒绝启动**。确实想在真机上跑：设环境变量 `MAACR_ALLOW_REMOTE=1` 显式放行（后果自负）。

## 日常任务

界面里「日常任务」分组有两项（领商店免费项、部落捐赠），
也可以直接用「**日常一条龙**」预设一把跑完（商店 + 部落，跑完自动回主界面）。

它们各自在判什么、为什么这么判，见 [2.2-日常任务](2.2-日常任务.md)。

## 跑起来之后出问题

看 [README 的「常见问题」](../../README.md#常见问题) 那张表 —— 按「现象」列了你该先看哪里，
覆盖最常撞到的几类：**屏幕熄了**导致全部识别 0.00、卡在某页不动、
点下去没反应、点开始报 `pretask failed`。

不想开界面、只想检查环境的话，包里自带 Python 可以直接跑：

```bash
python\python.exe tools\validate.py            # 项目自检：资源引用、节点名、选项配置
python\python.exe tools\preflight.py --check   # 只检查设备与模拟器状态，不做任何改动
```
