# logo 备选

**当前在用的是仓库根目录的 `logo.png`**（二次元猪猪版）。这里放的是换下来但**特意保留**的版本，
想换回去直接盖过去就行：

```bash
cp logo/01-boar-emblem.png logo.png
```

| 文件 | 风格 | 说明 |
| --- | --- | --- |
| ![初版野猪徽标](01-boar-emblem.png) | 扁平徽标 | 最早那版：金色野猪 + 斜插战锤 + 肩上齿轮，深蓝底。只有三四个纯色，缩到 60px 也认得出来 |
| ![二次元少女版](02-anime-girl.png) | 二次元 | 粉发骑士少女 + 木战锤 + 一只戴小铁盔的野猪崽。画风参考了「三月七」那张 app 图标，但**角色是原创的**，没有照抄 |

## 换 logo 只动一处

只改仓库根的 `logo.png` 就够了：

- `README.md` 头部引用的是 `./logo.png`；
- `tools/install.py` 会把它一起放进发布包（不然包里的 README 会挂一张碎图）。

## 约定

- **512×512 PNG**，圆角方形构图、自带浅色页边，README 里按 `width="200"` 显示。
- **带水印的图不许入库。** 生成器会在右下角打一行半透明白水印，入库前必须抹掉 ——
  做法与踩过的坑记在用户级文档里（`~/.workbuddy/tools/png_tool.py` 的注释也写了）。
  判断有没有抹干净要**放大目视**，别信自制的「亮度异常」指标（会被渐变骗过去）。
- 想加新版本就往这里放一个 `03-xxx.png` 并补一行表格，**不要覆盖已有文件** ——
  这一目录的用途就是「留着还能换回去」。
